# ER-012.1 — Source Foundation Consolidation Patch — Completion Report

**Patch:** ER-012.1 Source Foundation Consolidation  
**Date:** 22 July 2026  
**Base:** ER-012 Source & Acquisition Foundation

---

## Repository Analysis

Architecture review of ER-012 identified three consolidation gaps:

1. **Dual write path** — `ImportOperationsService` persisted sources via `ImportSourceRepository.save()`, bypassing `SourceService` validation (duplicate URLs, trust rules, archive rules).
2. **Trust default drift** — DB default `0`, application default `50`.
3. **Undocumented decisions** — Type vocabulary and URL duplicate strategy lacked explicit documentation.

No domain redesign was required.

---

## Changes Made

### Single write path

- `ImportOperationsService.saveSource()` → `SourceService.saveFromImportSource()`
- `ImportOperationsService.setSourceActive()` → `SourceService.setEnabled()`
- `ImportOperationsService.startManualImport()` metadata → `SourceService.recordImportRun()`
- Added `mapImportSourceToMutationInput()` in `source-mapper.ts`
- Added `createSourceServiceFromImportStore()` test bridge for isolated import test bundles
- Marked `ImportSourceRepository.save()` as deprecated for mutations (persistence-only)

`validateSourceConfig()` remains in `ImportOperationsService` (import adapter concern, not Source registry).

### Trust default alignment

- Introduced `SOURCE_DEFAULT_TRUST_SCORE = 50` in `source-types.ts`
- `validateSourceInput()` defaults omitted `trustScore` to 50
- Mapper read fallback: `row.trust_score ?? SOURCE_DEFAULT_TRUST_SCORE`
- `createDefaultSourceRecord()` and Admin CMS use the constant
- Migration `20260739000000_er012_1_source_foundation_consolidation.sql` sets DB default to 50

### Documentation

- New `app-v2/docs/sources-domain.md` — write path, type strategy, trust score, URL duplicate rationale
- Updated `AI_CONTEXT.md`

## Validation Consolidation

| Rule | Location |
|------|----------|
| Duplicate slug/URL | `SourceService` only |
| Slug / URL / trust / priority | `validateSourceInput()` via `SourceService` |
| Archive / enable rules | `SourceService` |
| Adapter config | `ImportOperationsService.validateSourceConfig()` |

## Trust Default Alignment

| Layer | Default |
|-------|---------|
| Database | `50` |
| Validation | `SOURCE_DEFAULT_TRUST_SCORE` (50) |
| Mapper read | 50 when null |
| Factory / CMS | 50 |

Range remains 0–100. Explicit `0` still valid.
