## 6. Besonderheiten

### 6.1 Dateinamen-Konvention

- Format: `{NN}_{Beschreibung}.png` (z. B. `09_Home.png`)
- Durchgängig englische Beschreibungen
- UI-Specs: Präfix `UI_` (52–61) oder `DesignSystem_` (62–69) oder Motion-Titel (70–79)

### 6.2 Sprache in Mockups

- **UI-Text:** überwiegend **Deutsch** (Home, Events, Admin)
- **Design-System-Sheets:** Deutsch + englische Token-Namen
- **Markenname:** „ETERNΛL RΛVE" mit Lambda-Ästhetik

### 6.3 Visuelle DNA (Mockup-Ära 2024)

| Merkmal | Häufigkeit | Evolution V2 Relevanz |
|---------|------------|----------------------|
| Reines Schwarz `#000000` als Hintergrund | Sehr häufig | → Weicher Dark (`#111214`) |
| Violett/Neon-Akzent + Gradient-Buttons | Sehr häufig | → Akzent sparsam, kein Gradient-CTA |
| Card-in-Card / schwere Borders | Häufig (Admin, Organizer) | → Reduktion |
| Stat-Card-Grids | Admin 41, Organizer 20, Analytics 34 | → StatInline |
| Bottom Nav 5 Tabs | Consumer 09–19 | ✅ Behalten |
| Admin Bottom Nav 7 Tabs | Admin 41–48 | → Sidebar (Desktop) |
| Skeleton-Spec vorhanden (60) | Spec only | → Implementieren |
| Toast-Spec vorhanden (61) | Spec only | → Implementieren |
| Light Mode | **Nicht vorhanden** | → Evolution V2 Pflicht |
| Glassmorphism / Glow | Design System 65, 68 | → Evolution V2 reduzieren |

### 6.4 Abweichungen zwischen Mockup-Specs

## 7. Designanalyse (nach vollständiger Inventarisierung)

### 7.1 Was die Mockups definieren

Die 85 Assets bilden ein **vollständiges Design- und Dokumentations-Ökosystem**:

1. **50 App-Screens** (01–51) — Consumer, Organizer, Admin, Support
2. **10 UI-Komponenten-Specs** (52–61) — implementierbare Bibliothek
3. **8 Design-System-Kapitel** (62–69) — Token-Grundlage
4. **10 Motion/Interaction-Specs** (70–79) — Verhalten und Feedback
5. **6 Documentation Bibles** (80–85) — strategischer, technischer und operativer Kontext

### 7.2 Kernerkenntnisse für Design Evolution V2

| Mockup-Muster | Bewertung | Evolution V2 |
|---------------|-----------|--------------|
| Flyer/Event-Bilder als Held | ✅ Stark | Behalten |
| 5-Tab Consumer Nav | ✅ Stark | Behalten |
| Filter Chips | ✅ Stark | Behalten |
| Dark Premium Basis | ✅ Gut | Weicher, weniger Kontrast |
| Form Wizard (5 Steps) | ✅ Gut | Behalten, weniger Card-Wrapper |
| Bottom Sheets für Filter | ✅ Gut | Generic Component |
| Skeleton Loading (60) | ✅ Spec | Implementieren |
| Toast (61) | ✅ Spec | Implementieren |
| Gradient Primary Buttons | ⚠️ Überladen | Entfernen |
| Glow / Neon-Effekte | ⚠️ Gaming-Nähe | Entfernen |
| Stat-Card Dashboards | ⚠️ Enterprise | → Inline Metrics |
| Admin 7-Tab Bottom Nav | ⚠️ Überladen | → Sidebar |
| Kein Light Mode | ❌ Lücke | Vollständiges Light System |
| Box-in-Box Cards | ❌ Clutter | Spacing statt Borders |
