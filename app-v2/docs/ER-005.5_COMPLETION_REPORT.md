## 2. Root cause — Event creation failure

| Issue | Root cause | Fix |
|-------|------------|-----|
| Drafts lost on refresh (local mode) | `LocalStore` was in-memory only; `EXPO_PUBLIC_USE_SUPABASE=false` default | AsyncStorage persistence for contributor `adminEvents` + bootstrap hydration |
| Supabase save FK failures | `cityId` hardcoded to `koeln` while staging seed uses `staging-seed-city-koeln` | `resolveContributorCityId()` validates against active cities |
| Duplicate drafts on Preview | Create mode always called `createEvent()` with new ID | Track `savedDraftId`; update after first save |
| Infinite edit spinner | `loadingDraft` never cleared on error/non-draft redirect | `.catch()` / `.finally()` on load |
| Unclear post-save UX | Success screen existed but was bypassed | Navigate to `/create/event/success` with action buttons |
| Stale My Events list | No refetch on screen focus | `useFocusEffect` reload |
| Silent image loss (local) | Upload returned `''`; images nulled without user feedback | Explicit validation error `imageRequiresSupabase` |
| Image re-upload blocked (Supabase) | Storage policy INSERT-only | Migration `20260731000000_contributor_event_image_update.sql` |

---

## 3. Root cause — Location failure

| Issue | Root cause | Fix |
|-------|------------|-----|
| Indefinite loading | No timeout on GPS or Nominatim | `withTimeout()` (15s GPS, 10s geocode) |
| Web HTTP failures | No secure-context check | `window.isSecureContext` guard |
| GPS success discarded | Hard-fail when geocode empty | Return coordinates without place names |
| Concurrent requests | Status-based guard only | `requestInFlightRef` |
| Hydration hang | No `finally` on storage load | `.finally(() => setHydrated(true))` |
| Save fails whole request | Storage throw propagated | Non-fatal persistence |
| No manual fallback | Modal had GPS only | Discovery city picker (Köln/Berlin) |
| Generic network errors | `network` code unused | Nominatim retry + `home.location.network` i18n |
