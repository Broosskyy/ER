# SEO — Eternal Rave

**Sprint:** 12.7D  
**Last updated:** July 2026

---

## 1. SEO architecture

Eternal Rave web is a **static Expo export** with client-side routing. SEO is handled via:

- Server-rendered HTML shell (`app/+html.tsx`) with global meta tags
- Per-route updates via `useWebSeo()` hook (title, description, canonical, OG, JSON-LD)
- `public/robots.txt` and `public/sitemap.xml` (generated)
- `EXPO_PUBLIC_WEB_NOINDEX=true` for staging

---

## 2. URL concept

| URL pattern | Indexable | Canonical |
|-------------|-----------|-----------|
| `/` | Yes | `https://www.<domain>.tld/` |
| `/search` | Yes | `/search` |
| `/saved` | Yes | `/saved` |
| `/notifications` | Yes | `/notifications` |
| `/event/:id` | Yes | `/event/:id` |
| `/collection/:type` | Yes | `/collection/:type` |
| `/privacy`, `/terms`, `/impressum` | Yes (when hosted) | respective path |
| `/admin/*` | **No** | no canonical |
| 404 | **No** | no canonical |

Set `EXPO_PUBLIC_WEB_BASE_URL` for absolute canonical and OG URLs.

## 4. Meta tag strategy

| Tag | Max length | Content |
|-----|------------|---------|
| `<title>` | ~60 chars | `{Page} — Eternal Rave` |
| `description` | ~160 chars | German description per page |
| `robots` | — | `index,follow` or `noindex,nofollow` |
| `canonical` | — | Absolute URL from base env |
| `theme-color` | — | `#0B0B0F` |
| `author` | — | Eternal Rave |
| `application-name` | — | Eternal Rave |

## 8. robots.txt

```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /_expo/
Disallow: /assets/
Sitemap: https://www.<domain>.tld/sitemap.xml
```

Generate: `npm run generate:seo`

---

## 9. sitemap.xml

Generated by `scripts/generate-seo-files.ts`:

| URL type | Priority | changefreq |
|----------|----------|------------|
| `/` | 1.0 | daily |
| `/search` | 0.9 | daily |
| `/collection/*` | 0.7 | daily |
| `/event/:id` | 0.8 | weekly |
| Legal pages | 0.3 | monthly |

**Dynamic events:** Pass `SEO_EVENT_IDS=id1,id2` at generation time, or regenerate at deploy from Supabase.

**Excluded:** `/admin/*`, 404, internal routes.
