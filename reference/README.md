# Reference Material — Eternal Rave

Dieser Ordner enthält den Export aus dem bisherigen Eternal-Rave-Projekt.  
**Nicht als App-Grundlage verwenden** — nur als Referenz für Mockups, Dokumentation, Assets und Datenmodelle.

## Struktur

```
reference/
├── mockups/
│   ├── archives/     # Original ZIP-Archive (8 Dateien)
│   └── screens/      # Entpackte Mockups (79 .jpg-Dateien)
├── assets/           # App-Icons, Onboarding-PNGs
├── docs/
│   ├── export-docs/  # Technische Dokumentation aus altem Projekt
│   └── Blueprint/    # Business-/Produkt-Blueprint
├── old-code/         # Teil-Export: src/, supabase/, Konfiguration
└── migration/
    └── migration_export.zip  # Original-Archiv (Kopie)
```
